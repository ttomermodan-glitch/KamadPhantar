פעילות מחלקה | סימולציית חודש מבצע (בדיוני)
אתר משחק קבוצתי עם שרת Node.js ללא תלויות, חיבור בזמן אמת, חמש תחנות המתפרשות על פני חודש בדוי במבצע באיראן, מסך הקרנה ופאנל אדמין.
הפעלה
העלו את תוכן תיקיית `news404-server` לתיקייה הראשית ב-GitHub. ודאו שקיים `public/index.html`.
ב-Render בחרו Node Web Service. פקודת ההפעלה: `node server.js`.
הגדירו משתנה סביבה `ADMIN_PASSWORD` עם סיסמה חדשה שאתם בוחרים. ברירת המחדל לצורך בדיקה מקומית היא `kamadP`.
האתר הראשי מיועד למשתתפים, `/#admin` למנהל ו-`/#screen` להקרנה.

מהלך הפעילות
חמישה סבבי עבודה בני שלוש דקות, כל אחד ביום אחר של החודש המדומה.
לכל סבב פרטים ייחודיים, משימות כתיבה לעיתונאות, שיחת כתב בדוברות ותכנון קונספט צילום ברשתות.
הנתונים עוברים לכולם בטלפונים ובמסך ההקרנה.
לאחר כל סבב כל ההגשות מוצגות לכולם במשך 75 שניות.
האדמין יכול ללחוץ על שם משתתף כדי להוציא אותו. המשתתף רשאי להיכנס מחדש באותו שם וקוד.
הדפדפן שולח אות חיים כל חמש שניות. השרת סורק מחוברים כל חמש שניות ומסיר מי שלא הגיב כ-12 שניות, בנוסף להסרה בעת יציאה מפורשת או ניתוק SSE.
משתתף שמצטרף לראשונה אחרי תחילת המשחק ממתין לאישור האדמין.
תרחיש בדיוני לצורכי למידה בלבד. אין להשתמש בנתוני התרחיש כמידע חדשותי אמיתי.
מגבלות
מצב המשחק וההגשות נשמרים בזיכרון השרת בלבד. אתחול השרת מאפס אותם.
שרת חינמי עלול להירדם אחרי תקופת חוסר פעילות. מומלץ לפתוח אותו מראש.
