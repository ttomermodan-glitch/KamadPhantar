# מקרה בוחן · נחלון: גרסת שרת בזמן אמת

שרת קטן (Node.js 18 ומעלה, בלי חבילות חיצוניות) שמחבר את כל המכשירים לאותו משחק:
משתתפים בטלפונים, מפקדים, מסך הקרנה ואדמין מהטלפון.

## הרצה בכיתה (בלי אינטרנט חיצוני)
1. מתקינים Node.js על מחשב נייד: https://nodejs.org
2. בתיקייה הזו: `node server.js`
3. מחברים את כולם לאותה רשת (Wi-Fi או נקודה חמה מהטלפון).
4. מוצאים את כתובת ה-IP של המחשב (למשל 192.168.1.20) ופותחים:
   - משתתפים ומפקדים: `http://192.168.1.20:3000`
   - מסך הקרנה: `http://192.168.1.20:3000/#screen`
   - אדמין (גם מהטלפון): `http://192.168.1.20:3000/#admin`

## העלאה לשרת באינטרנט
כל שירות שמריץ Node (Render, Railway, Fly.io, שרת וירטואלי): פקודת הפעלה `npm start`.
השירות קובע את `PORT` לבד, והחיבור חי (SSE) עובד בלי הגדרה נוספת.

## הגדרות
- סיסמת אדמין: משתנה סביבה `ADMIN_PASSWORD` (ברירת המחדל `kamadP`, כדאי להחליף).
- קודי כניסה ל-3 המגמות וקוד המפקדים: בקובץ `bank.json` (`TC` ו-`CC`), חמש ספרות כל אחד.
- אורך סבב: `RL` ב-`bank.json` (שניות, ברירת מחדל 180).

## איך זה עובד
- הקוד שמקלידים קובע את המגמה. מי שמצטרף אחרי שהמשחק התחיל מופיע ברשימת אישורים אצל האדמין.
- המשתתפים רואים רק את המשימה שלהם. מפקדים רואים כל תוצר בזמן אמת ומדרגים 1 עד 5 כוכבים.
- המנצח בכל מגמה נקבע לפי ממוצע דירוגי המפקדים בלבד, והאדמין חושף אותו אחד אחד.
- הכפתור "הרצה אוטומטית" ומצב הדמו מוסיפים 23 משתתפים מדומים לבדיקה.

## מגבלות
- המצב נשמר בזיכרון השרת: הפעלה מחדש מאפסת הכול. שרת אחד מריץ מחזור אחד בכל פעם.
- אין הצפנה בשרת עצמו. בשירותי אירוח האתר מקבל HTTPS מהשירות.
